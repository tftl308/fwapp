# Спецификация формата обмена плейлистами FWP (Flaming Wind Playlists)

Формат `.fwp` предназначен для быстрого и надежного обмена концертными списками, сетлистами богослужений и репетиционными подборками.

---

## 1. Режимы формата

### Режим A: Легковесный (`.fwp`)
Используется для отправки участникам команды, у которых уже загружена общая база песен.
Файл весит менее 2 КБ.

```json
{
  "format": "FWP",
  "version": "1.0",
  "type": "lightweight",
  "createdAt": "2026-09-25T10:00:00Z",
  "author": "Лидер группы",
  "playlist": {
    "id": "pl-sunday-morning",
    "title": "Воскресное служение 27 сентября",
    "date": "2026-09-27",
    "purpose": "Утреннее общее собрание",
    "items": [
      { "songId": "song-001", "order": 1, "note": "Интро фортепиано" },
      { "songId": "song-002", "order": 2, "note": "Куплет 1 а капелла" },
      { "songId": "song-004", "order": 3, "note": "Припев 2 раза" }
    ]
  }
}
```

*Примечание:* Согласно правилам команды, индивидуальные тональности в плейлисте исключены — все песни исполняются в канонической базовой тональности произведения.

---

## 2. Режим B: Автономный / Полный пакет (`.fwp` / `.fwp.json`)
Используется при передаче приглашенным музыкантам или на устройства с чистой/неполной базой.
Включает в себя полные тексты и аккорды песен:

```json
{
  "format": "FWP",
  "version": "1.0",
  "type": "standalone",
  "createdAt": "2026-09-25T10:00:00Z",
  "author": "Лидер группы",
  "playlist": {
    "id": "pl-easter-2026",
    "title": "Пасхальная программа",
    "date": "2026-04-12",
    "purpose": "Праздничный концерт",
    "items": [
      { "songId": "song-008", "order": 1, "note": "Торжественное открытие" }
    ]
  },
  "songs": [
    {
      "id": "song-008",
      "title": "Он воскрес из мертвых",
      "author": "Кузнецов В.",
      "key": "H",
      "tempo": "95",
      "time_signature": "4/4",
      "body_chordpro": "[H]Разрушив узы смерти, [E]Христос воскрес!...",
      "body_plain": "Разрушив узы смерти, Христос воскрес!..."
    }
  ]
}
```

При открытии автономного FWP приложение сверяет наличие песен в локальном каталоге:
- Если песня уже есть — связывается с существующей записью, сохраняя локальные пресеты музыканта.
- Если песни нет — автоматически предлагает добавить её в каталог без дубликатов.
