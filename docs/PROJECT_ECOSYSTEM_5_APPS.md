## 1. Единая модель песни (Канонические 22 поля `songs.csv`)

Все приложения экосистемы используют единый строгий контракт данных:
```text
id;number;title;author;key;capo;tempo;time_signature;duration;predelay;presentation;theme;alttheme;user1;user2;user3;lyrics;chordpro;notes;link_audio;link_youtube;custom_chords
```

1. **`id`** — 4-значный идентификатор с ведущими нулями (`0042`);
2. **`number`** — номер в сборнике (`42`);
3. **`title`** — название песни;
4. **`author`** — автор слов и музыки;
5. **`key`** — основная тональность (`Am`, `C#m`);
6. **`capo`** — лад каподастра (`+2`);
7. **`tempo`** — темп в BPM (`120`);
8. **`time_signature`** — музыкальный размер (`4/4`, `3/4`, `6/8`);
9. **`duration`** — продолжительность звучания (`04:20`);
10. **`predelay`** — задержка вступления / метронома (`2s`);
11. **`presentation`** — ссылка или разметка для проекции / презентаций;
12. **`theme`** — основная тема (`Поклонение`, `Благодарение`);
13. **`alttheme`** — дополнительная тема (`Рождество`, `Пасха`);
14. **`user1`** — пользовательская метка / фильтр 1;
15. **`user2`** — пользовательская метка / фильтр 2;
16. **`user3`** — пользовательская метка / фильтр 3;
17. **`lyrics`** — чистый текст песни без аккордов (для поиска и вокалистов);
18. **`chordpro`** — текст песни с аккордами в скобках (`[Am]Белый снег`);
19. **`notes`** — заметки ролей (`[leader]`, `[piano]`, `[drums]`);
20. **`link_audio`** — ссылка на оригинальное аудио / облако;
21. **`link_youtube`** — ссылка на видеозапись / разбор на YouTube;
22. **`custom_chords`** — нестандартные аппликатуры аккордов (`Am7b5:x02013`).

### Приложение №1: Портативный сборник SPA (Light Reader)
- **Целевая аудитория:** Вокалисты, слушатели и музыканты на узких смартфонах и планшетах, которым нужен **только текст с аккордами и списками**.
- **Ключевые свойства:**
  - Запускается мгновенно на любых мобильных устройствах;
  - Полностью прошитая база 700 песен с аккордами в OpenSong/ChordPro;
  - Полнофункциональный сценический режим «Концерт» с педальным автоскроллом и свайпами;
  - Составление локальных программ и плейлистов («Подбор») с возможностью делиться ими в JSON/тексте;
  - **Отличия:** в интерфейсе полностью отключен плеер фонограмм и блоки синхронизации аудио. Дистрибутив максимально легковесный и не требует места под гигабайты фонограмм.
- **Артефакт:** `dist/reader/index.html`.

---

### Приложение №2: Инженерная панель Data Studio (`data/admin.html`)
- **Целевая аудитория:** Руководитель группы, звукорежиссёр, администратор архива.
- **Ключевые свойства:**
  - Полная компиляция, аудит и редактирование всех **22 полей базы `songs.csv`** через удобное модальное окно;
  - Умное распознавание архивов песен из Microsoft Word (`.docx`) с пропорциональным шрифтом Times New Roman через алгоритм Dynamic Programming;
  - Двусторонний синхронный Drag-and-Drop редактор: слева перетаскивание аккордов мышью над слогами, справа — правка текста пробелами;
  - Пакетная оцифровка и экспорт в формат OpenSong XML с нормализованными именами (`0042_Адонай.xml`);
  - Подсветка обработанных песен зелёным цветом (`✓ OpenSong`);
  - Пакетная генерация сборников для печати в PDF и DOCX;
  - Автоматическое создание резервных копий перед любыми изменениями.
- **Артефакт:** `data/admin.html`.

### Приложения №3, №4, №5: Полнофункциональные терминалы музыканта с плеером фонограмм и синхронизацией

Внешне и по интерфейсу эти три приложения абсолютно идентичны, но используют специализированные драйверы файловой системы под свои платформы:

#### Приложение №3: Web Desktop PWA (для компьютеров и ноутбуков)
- **Платформа:** Windows, macOS, Linux (включая Альт Образование 10.4).
- **Хранение медиа:** **OPFS (Origin Private File System)** — фонограммы скачиваются в изолированное дисковое пространство браузера через потоки `ReadableStream.pipeTo()`, никогда не нагружая оперативную память и не попадая в IndexedDB.
- **Синхронизация:** Движок `SyncEngine` по манифесту `manifest.json` с проверкой контрольных сумм SHA-256.
- **Артефакт:** `dist/pwa/index.html` + `sw.js`.

#### Приложение №4: Android Native APK (для смартфонов и планшетов)
- **Платформа:** Android (Samsung, Xiaomi HyperOS/MIUI, Huawei и др.).
- **Хранение медиа:** Нативная файловая система Android (`Directory.Data`).
- **Специфика:**
  - Аудиопоток не блокируется операционной системой благодаря `FOREGROUND_SERVICE_MEDIA_PLAYBACK`;
  - Экран не гаснет на сцене благодаря флагу `WAKE_LOCK`;
  - Воспроизведение треков через нативный безопасный мост `Capacitor.convertFileSrc()`.
- **Артефакт:** `capacitor-app/android/` ➔ `app-debug.apk`.

#### Приложение №5: iOS Native App (для iPhone и iPad)
- **Платформа:** Apple iOS / iPadOS.
- **Хранение медиа:** Изолированная директория `Directory.Library` с обязательным атрибутом `NSURLIsExcludedFromBackupKey = true` (чтобы медиатека не забивала облако iCloud пользователя).
- **Специфика:** Настроен фоновый режим аудио `UIBackgroundModes: [audio]` в `Info.plist`, системная интеграция с экраном блокировки Apple через `navigator.mediaSession`.
- **Артефакт:** `capacitor-app/ios/`.
