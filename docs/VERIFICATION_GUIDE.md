### Архитектурное разграничение:
1. **`index.html` (PWA) НЕ компилирует SPA** — PWA служит полнофункциональным плеером и песенником для музыкантов на компьютерах и мобильных устройствах.
2. **Только `data/admin.html` (Data Studio) компилирует автономный SPA `огненныйветер.html`** — администратор управляет оцифровкой, редактирует 22 поля, экспортирует OpenSong и одной кнопкой собирает чистый карманный сборник для раздачи.

## 2. Канонический стандарт базы данных (22 поля)

База `data/songs.csv` строго структурирована через точку с запятой (`;`) со следующим набором заголовков:
```csv
id;number;title;author;key;capo;tempo;time_signature;duration;predelay;presentation;theme;alttheme;user1;user2;user3;lyrics;chordpro;notes;link_audio;link_youtube;custom_chords
```

- `id`: 4-значный канонический идентификатор выхода (`0001` - `0700`);
- `title`, `author`: название и автор песни;
- `key`, `capo`, `tempo`, `time_signature`: музыкальные параметры исполнения;
- `lyrics`: текст песни в формате OpenSong (строки с аккордами начинаются с точки `.Am`, строки текста — с пробела ` текст`);
- `chordpro`: текст в формате ChordPro (`[Am]текст`);
- `notes`: сводные заметки музыкантов с тегами инструментов (`[leader]`, `[piano]`, `[bayan]`, `[electric]`, `[bass]`, `[drums]`);
- `link_audio`, `link_youtube`: прямые ссылки на внешние аудиозаписи и YouTube-разборы.

## 3. Чек-лист проверки компонентов

### Проверка 1: Автономный Light Reader SPA (`огненныйветер.html`)
1. **Запуск:** Откройте файл `огненныйветер.html` двойным кликом в браузере (по протоколу `file://`, без запуска сервера).
2. **Каталог:** Сразу отображаются все 700 песен с мгновенным поиском по названиям и тексту.
3. **Отсутствие плеера:** В нижней навигации и на карточке песни нет фонограммного плеера.
4. **Внешние ссылки:** В карточке песни при наличии ссылок появляются кнопки `🎧 Слушать оригинал ↗` и `▶ YouTube разбор ↗`, открывающиеся в новой вкладке.
5. **Вкладка «Списки»:**
   - Панель кнопок списка имеет размеры `flex items-center justify-between gap-1 text-sm flex-wrap` (кнопки `min-width: 38px`, `min-height: 38px`, гармонично сгруппированы).
6. **Вкладка «Опции» (Настройки):**
   - Разделы строго по порядку:
     1. ⛶ Полноэкранный режим;
     2. 🎨 Цветовая схема;
     3. 🎸 Режим работы (профиль музыканта);
     4. 📤 Экспорт заметок;
     5. 🛠 Диагностический лог.
   - Никаких лишних технических кнопок на экране нет.

### Проверка 2: Инженерный пульт Data Studio (`data/admin.html`)
1. **Запуск:** Откройте `data/admin.html`.
2. **Импорт базы:** Во вкладке «1. Импорт сборника DOCX» выберите `2. Загрузить songs.csv`. База мгновенно попадает в интерактивный визуальный редактор.
3. **Редактор аккордов:**
   - Аккорды выводятся корректно над слогами (без ошибок `[undefined]`);
   - Первые строки песен и разметка OpenSong не ломаются.
4. **Кнопка тэгов:**
   - В тулбаре редактора аккордов нажмите `🏷️ Тэги и поля (22 поля)` — открывается модальное окно с полным набором 22 канонических параметров.
5. **Компиляция SPA:**
   - Нажмите `⚡ Скомпилировать и скачать огненныйветер.html` в шапке или вкладке 4;
   - Браузер скачивает готовый автономный файл `огненныйветер.html` (1.81 МБ) без запросов доступа к диску.

### Проверка 3: Компьютерное и мобильное PWA (`index.html`)
1. **Запуск:** Откройте `index.html` (или запустите локальный сервер `npm run dev`).
2. **Аудиоплеер:** Полнофункциональный плеер с фонограммами (`альбом`, `запись`, `минус`, `импро`).
3. **Локальная музыка:** Во вкладке «Опции» доступна синхронизация с папкой `music/` и сканирование файлов по маске `ID_title.mp3`.

## 4. Автоматизированные тесты экосистемы

Для проверки целостности модулей выполните в терминале проекта:
```bash
npm test
```
Тестовый комплекс валидирует:
- 20 модульных и интеграционных тестов;
- Полноту транспонирования аккордов (европейская и немецкая нотации H/B);
- Парсер ChordPro и OpenSong XML roundtrip;
- Алгоритмы нечёткого поиска и поиска по согласным («блй снг» -> «Белый снег»);
- Хранилище IndexedDB и бесконфликтное объединение заметок музыкантов.
