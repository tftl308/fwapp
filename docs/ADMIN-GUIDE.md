# Руководство администратора по редактированию базы в таблицах

Это руководство объясняет, как наполнять и редактировать базу песен через таблицы (Microsoft Excel, LibreOffice Calc, МойОфис, Google Таблицы).

---

## 1. Структура пакета данных

Пакет данных состоит из CSV-файлов, объединенных общим манифестом:

- `manifest.json` — версия схемы, описание пакета, дата формирования и контрольные суммы.
- `songs.csv` — каталог песен, тексты, тональности, темп, каподастр, метаданные.
- `tags.csv` — справочник тегов (категории, названия, цвета для бейджей).
- `song_tags.csv` — связь многие-ко-многим: какая песня какими тегами отмечена.
- `audio.csv` — привязка аудиозаписей (оригинал, минус, репетиция, демо, лайв).
- `resources.csv` — ссылки на полезные материалы (ноты, видеоразборы, фонограммы).
- `playlists.csv` — списки песен (сетлисты для служений, репетиций, концертов).
- `playlist_items.csv` — состав плейлистов с индивидуальной тональностью и заметками.

## 2. Главные правила для Excel

1. **Разделитель колонок — точка с запятой (`;`)**.
   Русская версия Excel по умолчанию ожидает именно `;`.
2. **Кодировка — UTF-8**.
   При экспорте из приложения файл уже содержит метку порядка байтов (BOM), поэтому русские буквы открываются без «кракозябр».
3. **Многострочный текст песен**:
   Текст песни с аккордами хранится в одной ячейке (`body_chordpro`). Внутри ячейки переводы строк делаются через `Alt + Enter` (в Excel) или `Ctrl + Enter`.
4. **Безопасность формул**:
   Если текст строки начинается со знаков `=`, `+`, `-` или `@`, приложение автоматически защищает ячейку апострофом `'`, чтобы Excel не воспринимал её как математическую формулу.

## 3. Описание полей таблицы `songs.csv`

| Колонка | Назначение | Пример |
|---|---|---|
| `id` | Уникальный стабильный идентификатор (латиница, цифры, дефис). Не менять у существующих песен! | `blagodat-i-lyubov`, `song-001` |
| `number` | Порядковый номер в сборнике (если есть) | `42` |
| `title` | Основное название песни | `О, благодать` |
| `alt_title` | Альтернативное название или узнаваемая первая строка | `Amazing Grace` |
| `author` | Автор слов и/или музыки | `Джон Ньютон` |
| `copyright` | Авторские права / лицензия | `Public Domain` |
| `key` | Основная тональность (Am, C, F#m, Hbm) | `G` |
| `capo` | Позиция каподастра (оставьте пустым, если каподастр не нужен) | `+2` или пусто |
| `tempo` | Темп в ударах в минуту (BPM) | `76` |
| `time_signature` | Музыкальный размер | `4/4`, `3/4`, `6/8` |
| `body_chordpro` | Текст с аккордами в каноническом формате ChordPro | См. раздел 4 |
| `body_plain` | Чистый текст без аккордов (при импорте формируется автоматически, если оставить пустым) | `О благодать спасен тобой...` |
| `album` | Альбом | `Сборник гимнов` |
| `year` | Год создания / публикации | `1779` |
| `notes` | Заметки для музыкантов (порядок частей, вступление) | `Интро: гитара соло 4 такта` |

## 4. Как оформлять текст с аккордами (`body_chordpro`)

Приложение поддерживает два удобных способа записи:

### Способ 1: ChordPro inline (рекомендуется)
Аккорд заключается в квадратные скобки прямо перед слогом:
```text
[G]О, благо[G7]дать, спасен то[C]бой
Я [G]был из тьмы су[D7]ет.
```

### Способ 2: Строки аккордов с точкой (OpenSong-стиль)
Строка аккордов начинается с символа `.` и располагается над строкой текста:
```text
.G      G7           C
О, благодать, спасен тобой
.   G           D7
Я был из тьмы сует.
```
При сохранении приложение автоматически преобразует такой текст в надежный формат ChordPro.

## 5. Как связать песню с тегами и аудио

1. Чтобы присвоить песне тег, откройте `song_tags.csv` и добавьте строку:
   `blagodat-i-lyubov;worship` (где `worship` — `id` тега из `tags.csv`).
2. Чтобы привязать аудиофайл, откройте `audio.csv` и добавьте:
   `aud-01;blagodat-i-lyubov;Оригинал студийный;original;music/blagodat.mp3;;blagodat.mp3;audio/mpeg;John Newton;;1779`
   Поместите MP3-файл в папку `music/` рядом с `index.html`.
