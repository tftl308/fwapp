# Инструкция для Администратора (Каталог и Релизы)
**Система: «Огненный Ветер» v4.0.0 (Capacitor + PWA Dual-Track)**

---

## 1. Источник Истины (Single Source of Truth)

1. **Каталог песен:** строго файл `data/songs.csv` (разделитель `;`, кодировка UTF-8).
2. **Фонограммы:** директория `music/` с файлами формата `0482_тип_Название.mp3`:
   - Допустимые типы: `альбом`, `запись`, `запись2`...`запись9`, `минус`, `импро`.
3. **Плейлисты и заметки музыкантов:** хранятся изолированно на устройствах музыкантов и никогда не перезаписываются при обновлении каталога.

---

## 2. Сборка нового релиза базы и медиатеки

Когда вы добавили или отредактировали песни в `data/songs.csv` или скопировали новые треки в `music/`:

```bash
# 1. Генерация манифеста релизов с SHA-256 и реестра audio.csv
npm run build:data

# 2. Сборка единого веб-ядра и модулей
npm run build

# 3. Запуск тестов целостности
npm test
```

Команда `npm run build:data`:
- Пересчитает SHA-256 для каждого аудиофайла в папке `music/`;
- Сгенерирует атомарный `manifest.json`;
- Обновит `data/audio.csv` без ручного ввода;
- Подготовит дистрибутивы `dist/pwa/` и `capacitor-app/www/`.

---

## 3. Раздача обновлений на репетиции

На репетиционной точке (даже без доступа в интернет):

```bash
# Запуск локального сервера с раздачей полной медиатеки
npm run dev:server
# либо напрямую:
python3 start_offline_server.py --serve-files
```

- Ноутбук показывает адрес в локальной Wi-Fi сети (например: `http://192.168.1.45:8080`).
- Музыканты открывают этот адрес на смартфонах. Приложение в фоне сверяет `manifest.json`, скачивает только новые треки через пул потоков и проверяет целостность по SHA-256.
