# Музыка Огненного Ветра — Офлайн-сборник песен, аккордов, сетлистов и аудиоплеер

Автономное мобильное веб-приложение (SPA) для музыкантов, лидеров прославления и слушателей.

Работает **из одного самостоятельного файла `огненныйветер.html` (или `index.html`)**, открываемого двойным щелчком в любом современном браузере без установки Node.js, веб-сервера и без подключения к интернету.

---

## Фактические возможности приложения

1. **Каталог и быстрый поиск песен**:
   - Мгновенный поиск по названиям, авторам и ключевым фразам.
   - Независимый изолированный рендеринг: ввод в строку поиска обновляет только список результатов без пересоздания DOM-дерева и потери фокуса ввода.
   - Подсветка совпадений и пагинация каталога кнопкой «Показать ещё» (по 60 записей).
   - Индикация пустых результатов («Ничего не найдено по вашему запросу»).
   - Маркировка песен из реестра, тексты которых ожидаются («Только название»).

2. **Просмотр песен, аккорды и печать**:
   - Транспонирование на лету с сохранением знаков альтерации (# и b).
   - Транспонирование басовых нот в слэш-аккордах (`A/C#` -> `H/D#`).
   - Переключение музыкальной нотации: европейская **H** (H, B) или англо-американская **B** (B, Bb).
   - Слоговая верстка ChordPro (`inline-flex` блоков): аккорды жестко привязаны к слогам и аккуратно переносятся на смартфонах без смещения.
   - Печать текста с аккордами на принтер или сохранение в PDF через кнопку **«Печать»** в шапке песни (`window.print()`).

3. **Сетлисты и управление списками**:
   - Создание и редактирование сетлистов («Служение», «Концерт», «Репетиция»).
   - Изменение порядка песен в сетлисте через Drag & Drop (`draggable=true`) и кнопками «Вверх» / «Вниз».
   - Кнопка **«Редактировать»** в разделе списков для безопасной загрузки любого сетлиста в двухколоночный рабочий экран песен (с подтверждением).
   - Drag & drop сортировка самих списков с сохранением локального порядка и сортировкой по дате обновления (`updated_at`).
   - Мобильный переключатель вкладок «Каталог» / «Сетлист» для узких экранов.

4. **Сценический режим (Концерт)**:
   - Полноэкранный интерфейс с крупным адаптивным шрифтом.
   - Раздельный контекст: запуск концерта сохраняет активный рабочий сетлист в каталоге (`concertPlaylistId`).
   - Настройка тем: ночная сцена («Янтарь»), «Бумага», «Терракота».
   - Автопрокрутка с настройкой скорости и перелистывание песен клавишами стрелок / PageUp / PageDown.
   - Предотвращение засыпания экрана через Screen Wake Lock API.

5. **Встроенный аудиоплеер**:
   - Поддержка воспроизведения оригиналов, репетиционных дублей (`rep1`, `rep2`), фонограмм (`minus`) и живых записей (`live1`).
   - Плавный высокопроизводительный прогресс воспроизведения через `requestAnimationFrame` и прямой DOM-апдейт (без лишних `setState` и задержек).
   - Воспроизведение сетлиста и всех версий конкретной песни.
   - Защита состояния: кнопки воспроизведения блокируются (`disabled`), если в очереди нет доступных аудиофайлов.
   - Безопасное хранение очереди: в IndexedDB сохраняются только метаданные треков без временных Blob Object URL.
   - Интеграция с системным Media Session API.

6. **Профили музыкантов и заметки**:
   - Доступные роли: Руководитель / Вокал / Акустика (`leader`), Фортепиано (`piano`), Баян (`bayan`), Электрогитара (`electric`), Бас-гитара (`bass`), Барабаны (`drums`).
   - Режим по умолчанию: «Обычный пользователь (Слушатель)» (`none`), при этом выбранный профиль запоминается на устройстве.
   - В блоке песни отображается роль «Общие заметки (Лидер)».
   - Единое поле заметок с тегированием `[profile]` и дедупликацией общих заметок.
   - Сохранение заметки обновляет только одну песню (`storage.putOne`) без перезаписи всей базы.
   - Экспорт и импорт заметок в JSON для синхронизации с лидером группы.

7. **Система отмены (Undo)**:
   - История изменений (перемещение песен, удаление из сетлиста, редактирование заметок) с возможностью отката по кнопке «Отмена».

8. **Надежность и офлайн-хранилище**:
   - Архитектура IndexedDB с автоматическим резервным переключением на localStorage.
   - Защита от переполнения квоты памяти (`QuotaExceededError`) с предупреждающими тостами.
   - Защищенный парсинг CSV с валидацией обязательных идентификаторов.

## Дисклеймер об импорте сторонних форматов

- **Канонический формат базы**: Данные поставляются во встроенном JSON-бандле и стандартных таблицах CSV (`songs.csv`, `audio.csv`, `playlists.csv`, `user_notes.csv`).
- **Синхронизация заметок и сетлистов**: Поддерживается экспорт и импорт в формате JSON.
- **Внешние форматы (DOCX, OpenSong XML, TXT, пакетный ZIP)**: Парсеры и конвертеры внешних файлов реализованы в виде утилит в `data/admin.html` и наборе тестов `tests/unit-tests.mjs`. В основном офлайн-файле приложения реализован импорт структурированных JSON-заметок и пакетная привязка аудиофайлов `ID_type_title`.

## Быстрый старт

1. Скопируйте файл `огненныйветер.html` (или `index.html`) на любое устройство.
2. Откройте файл в браузере.
3. Приложение мгновенно готово к работе полностью офлайн.
